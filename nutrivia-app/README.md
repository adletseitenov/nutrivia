# Nutrivia — мобильное приложение

Клиентское приложение на Expo SDK 58 и Expo Router. Внешний вид взят из дизайн-системы Nutrivia и холста экранов в Claude Design: белый, чёрный и зелёный, шрифт Onest.

## Запуск

Сначала сервер (`../nutrivia-bot`):

```bash
cd ../nutrivia-bot && .venv/bin/python -m nutrivia.api
```

Без ключа Anthropic сервер можно запустить с `VISION_PROVIDER=fake`, тогда разбор будет заглушкой. Затем приложение:

```bash
npm install
npx expo start
```

Адрес сервера задаётся в `EXPO_PUBLIC_API_URL`, по умолчанию `http://localhost:8000`: этот адрес работает в симуляторе iOS. Для телефона укажите IP компьютера в сети, например `http://192.168.1.10:8000`.

Затем нажмите `i`, чтобы открыть приложение в симуляторе iOS (через Expo Go), или отсканируйте QR-код телефоном с установленным Expo Go.

В симуляторе нет камеры, поэтому кнопка съёмки подставляет демо-фото плова. На реальном телефоне работает настоящая камера.

## Проверки

```bash
npm run typecheck
npx eslint src
npm run test:engine
```

`test:engine` проверяет расчёт: 150 г курицы = 248 ккал / 46,5 Б / 5,4 Ж. Результат должен совпадать с ботом.

## Экраны

| Маршрут | Экран |
|---|---|
| `/welcome` | Приветствие, согласие, «Войти» |
| `/role` | Тип аккаунта: для себя, тренер, нутрициолог |
| `/pro-name` | Имя специалиста |
| `/phone`, `/code` | Вход по номеру и коду из SMS |
| `/pro` | Кабинет тренера или нутрициолога: код приглашения и ученики |
| `/join` | Ввод кода тренера из профиля |
| `/meal` | Приём пищи клиента: фото, блюда, статус, кто проверил и комментарий; открывается с карточки на «Сегодня» |
| `/pro-review` | Проверка разбора специалистом: порции, замена блюда, комментарий, «Отправить» |
| `/goal` | Выбор цели |
| `/(tabs)/today` | Сегодня: кольцо калорий, БЖУ, приёмы пищи |
| `/(tabs)/feed` | Лента сообщества |
| `/(tabs)/progress` | Итог недели |
| `/(tabs)/profile` | Профиль |
| `/camera` | Камера с режимами «Еда» и «Холодильник» |
| `/review` | Разбор фото, порции меняются шагом ½ |
| `/fridge` | Что приготовить из холодильника |
| `/streak` | Серия, стадии маскота, задания дня |

## Как устроено

- `src/theme/tokens.ts` — токены дизайн-системы. Цвета меняются только вместе с ней.
- `src/engine/` — расчёт `per_100g × grams / 100` и база блюд. Файл `dishes.ts` сгенерирован из `nutrivia-bot/data/dishes.csv`.
- `src/components/` — компоненты дизайн-системы: Button, StatusPill, CalorieRing, MacroCard, MealCard, MascotSlot, TabBar.
- `src/store/app-store.tsx` — кеш ответов сервера. При запуске загружается `GET /v1/today` и обновляется при открытии вкладки «Сегодня». Пока есть непроверенные разборы, обновляется раз в 15 секунд.
- Серия дней, стадия маскота и неделя в «Прогрессе» приходят с сервера (`GET /v1/progress`). Задания «фото завтрака / обеда / ужина» засчитываются по реальным приёмам пищи, «совет на вечер» отмечается вручную и пока не сохраняется на сервере.
- `src/components/add-dish-sheet.tsx` — «Добавить блюдо», поиск по базе сервера.
- `src/api/client.ts` — клиент API: регистрация, загрузка фото, правка порций, «Верно», проверка статуса.
- `src/api/vision.ts` — **заглушка** только для холодильника.

## Что пока не сделано

- **Холодильник** пока на заглушке: на сервере его ещё нет.
- **Настоящая отправка SMS.** Сервер пока пишет код в свой лог. Провайдер для Казахстана ещё не выбран.
- **Казахский язык.** Тексты пока только на русском и прямо в экранах. Перед бетой их нужно вынести в файлы локализации ru и kk.
- **Маскот и иконка приложения.** Ждём файлы. Маскота подключать в `MASCOT_STAGES` (`src/components/mascot-slot.tsx`), иконку — в `app.json`.
- **Лента** — демо: на сервере её нет.
- В симуляторе код из SMS берите из лога сервера (`DEV SMS to …`).

# Лаунч-видео Nutrivia (для инвесторов и жюри)

68 с, 1920×1080, 30 fps, голос + музыка, звук −14 LUFS. Собрано в Remotion из настоящих записей экрана приложения
(на стоковых фото работал **настоящий** ИИ: плов → «Плов с говядиной 1½ пиалы ≈450 г + салат, 915 ккал»;
фото продуктов → «яйца, молоко» → «Омлет на молоке»).

## Сценарий (голос)
`vo/script.json` — 9 реплик. Озвучка: Fish Audio через OpenRouter (бесплатная модель), `python3 vo/tts.py [сцена]`.
Тайминги слов (для синхронизации текста на экране): `vo/words.py` (faster-whisper) → `vo/words.json` → копия в `src/lib/words.json`.

## Пересобрать
```
npm install
npm run render                       # out/nutrivia-launch.mp4
sh tools/master.sh out/nutrivia-launch.mp4   # громкость −14 LUFS → *.master.mp4
npm run studio                       # правки с предпросмотром
```
Медиа (`public/media/`) не в репозитории: стоки, музыка, озвучка, записи экрана — у автора локально.

### Записи экрана заново
1. Демо-база и сервер «как будто 5 ноября 19:20» с настоящим ИИ (бот выключен):
   `DEMO_NOW=2026-11-05T17:10 DB_PATH=data/launch.db … python -m scripts.demo_seed`,
   затем `SERVER_NOW=2026-11-05T19:20 … python ../launch-video/tools/server_at.py` (порт 8002).
2. Токены демо-клиента и тренера → `/tmp/nv-launch-client`, `/tmp/nv-launch-trainer`; стоковые фото → `nutrivia-app/dist/stock/`.
3. `cp launch-video/tools/footage.mjs e2e/x.mjs` (нужен Playwright из e2e), поправить OUT на `../launch-video/public/media/clips`, `node x.mjs`.
4. В конец записей добавлен стоп-кадр: `ffmpeg -i c.mp4 -vf tpad=stop_mode=clone:stop_duration=8 …`.
